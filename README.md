# 🎓 Exam Result Management System

A web-based application to manage student exam results, calculate percentages, and generate rank lists. Built with Python, Flask, SQLite, and Pandas.

## 🚀 Features
- **Add Student Records:** Securely add roll number, name, and marks.
- **Automatic Calculations:** Calculates Total, Percentage, and Pass/Fail status.
- **Rank Generation:** Dynamic rank list sorted by total marks.
- **Data Validation:** Prevents duplicate roll numbers and invalid marks (0-100).
- **Persistent Storage:** Uses SQLite database for storing records.

## 🛠️ Tech Stack
- **Backend:** Python 3, Flask
- **Database:** SQLite3
- **Data Processing:** Pandas
- **Frontend:** HTML, CSS, Jinja2
